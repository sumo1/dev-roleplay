# Background

task-designer 在开工前对相关模块的代码探索结论。

放这里的内容必须是**可以反复回看的事实**，而不是过程性叙事：

- 现有模块的边界和职责
- 可复用的模式（已有类似功能怎么做的）
- 需要注意的耦合点或约束
- 竞品调研、外部 API 行为摘要（如有）

每一条都要附**代码引用**——文件路径、行号或函数名。让下一个回看的人 5 分钟内能定位到原始证据。
