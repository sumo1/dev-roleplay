# Todo 按标签过滤

## 目标

Todo 服务支持 `GET /todos?tag={name}` 接口，按标签过滤返回的 Todo 列表，接口契约、性能、数据一致性均满足项目规范。

## 背景

- 用户反馈列表展开后找不到特定主题的 todo
- 已有数据：Todo 实体已有 `tags: string[]` 字段，但无索引

## 步骤
